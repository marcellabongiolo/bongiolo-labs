# Research

Research at Bongiolo Labs is focused on technical experimentation.

## Current directions

- Temporal AI
- Spatial computing
- Simulation
- Multimodal systems
- Machine learning
- Distributed systems

## Research workflow

```text
Question
 ↓
Hypothesis
 ↓
Experiment
 ↓
Measurement
 ↓
Analysis
 ↓
Documentation
```

Experiments should be reproducible whenever practical, and limitations should be documented clearly.
