# Cloud & Platform

This area will contain infrastructure and platform-engineering experiments.

## Planned capabilities

- APIs
- Containers
- CI/CD
- Infrastructure as Code
- Observability
- Distributed systems
- Service reliability

## Target architecture

```text
Developer
   ↓
Platform
   ├── Build
   ├── Test
   ├── Deploy
   ├── Observe
   └── Operate
```

The platform layer will be introduced gradually as the products require it.
